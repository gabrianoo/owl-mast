# automation

Engineering automation for Owl Mast, separate from the product backend.

- `unattended/` — the unattended execution foundation (ENG-01): GitHub-authoritative dispatch, synchronization and T3 coordination policy. On the real GitHub transport every state command is opt-in only: it needs a current, run-bound activation authorization (`--activation`); the shipped policy and the committed candidate activation are unapproved and refuse. Guide: [docs/unattended-execution.md](../docs/unattended-execution.md).
- `policy.toml` — default policy (empty allowlist: nothing dispatchable). `examples/first-run-om-01-02.toml` is the candidate first-run policy and `examples/activation-om-01-02.candidate.toml` the unapproved candidate activation (never commit an approved one).
- `tests/` — stdlib `unittest` qualification suite with an in-memory GitHub transport and the real backlog snapshot fixture. Run `python3 -m unittest discover -s automation/tests -t .` from the repository root (Python 3.12, no dependencies). `tests/test_final_findings.py` covers the six defects of the final PR #107 disposition, `tests/test_fresh_review_findings.py` the four code findings of the fresh review of remediation pass 1 `tests/test_activation.py` the explicit opt-in (admission, drift, expiry, cleanup, restart, CLI default refusal), `tests/test_enabling_repair_1.py` the six findings of the independent review of the enabling change (missing run metadata, binding provenance, source re-read, strict timestamps, nested target keys, durable expiry stop), `tests/test_enabling_repair_2.py` and `tests/test_enabling_repair_3.py` the later rounds (foreign run record, persisted temporal facts, status under the gate; source re-read at creation, one clock observation per operation) and `tests/test_repair_pass_2_findings.py` the two findings of the fresh review of repair pass 1 (unresolved task authorizations as ownership obligations; done-intent reconciliation behind every fresh-attempt gate); `PYTHONPATH=. python3 automation/tests/probe_final_findings.py`, `… probe_fresh_review_findings.py` and `… probe_repair_pass_2_findings.py` re-run those scenarios as readable transcripts.
