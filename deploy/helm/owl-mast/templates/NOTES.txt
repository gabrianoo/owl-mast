{{- if .Values.database.bundled }}

NOTE: the bundled PostgreSQL has no TLS: the application and Keycloak connect with sslmode=disable, so
credentials and data cross the pod network unencrypted. Isolation relies on the NetworkPolicy
({{ ternary "rendered" "DISABLED by networkPolicy.enabled=false" (dig "enabled" true (.Values.networkPolicy | default dict)) }}) and on the cluster network. Where the pod network is not trusted, an
external PostgreSQL with sslMode=require encrypts the connection but does NOT authenticate the server: an
active interceptor can still pose as the database and collect the credentials. Server authentication
(sslMode=verify-full with a mounted CA) is not shipped yet (deferred, docs/installation.md).
{{- end }}
