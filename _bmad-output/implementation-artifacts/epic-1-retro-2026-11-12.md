### Aggregate views

**Architecture delta**

- **A1:** `FeatureModuleRules` does not enforce the layering table in `docs/engineering-conventions.md`. Current violations: `audit/domain/AuditRecord.java:3-7` imports 5 `audit.api` types; `jobs/domain/RetryPolicy.java:3` imports `jobs.api`; `audit/api/AuditEnvelopeContract.java:3` and `AuditIdentifiers.java:3` import `jobs.api` (api→foreign api). The rule test excludes test sources, and `AuditedMutationIT.java:28-32` imports `jobs.application`/`domain`/`port`. Two rules (no cycles; api/domain free of Spring) have no negative fixture. **Fix:** either align the rules with the doc or the doc with the code. Lesson: every convention-table row needs a rule plus a negative fixture.
- **A2:** the shared kernel has grown past its documented scope: `platform/authorization` (OM-01.03, "raised by E02") and `platform/web` (OM-01.04). `access` is adapter-only. **Accept**, and update the conventions doc.
- **A3:** there is a frontend folder cycle, `app→routes→app` (`App.tsx:4-7`; `routes/ConnectionPanel.tsx:3-4`), and no import-boundary lint. **Defer.**

**Duplication map**

- **D1:** the API path prefix is validated in 4 places with 3 different rules: `_helpers.tpl:515-520,375`, `docker-entrypoint.d/16-owlmast-api-prefix.envsh`, `src/api/config.ts:14-38`, and `CompatibilityController.java:19`. **Defer**, and pick one source of truth when E02 adds routes.
- **D2:** issuer validation exists in both Java and Helm regex, kept in step by a shared sample file. It is guarded, so **accept**.
- **D3:** OM-01.03 builds the "processor" shape twice: `WorkProcessor.Dispatch` and `AuditedMutationService.Attempt`, with paired nested exceptions and `reasonFor`. **Defer**, to be refactored with S1.
- **D4:** the version literal `0.1.0` is set by hand in about 8 places, and the backend reports `0.1.0-SNAPSHOT` while the chart/image say `0.1.0`. **Defer** to E18 release work.

**Size growth**

- **S1:** `jobs/application/WorkProcessor.java` is 579 lines, 12% of main code, with 7 documented responsibilities and a nested mutable state machine (`:478-554`). It is the god-class candidate. **Defer** a split (claim/dispatch vs. settle) until the next jobs change.
- **S2:** `DurableWorkIT.java` (2055 lines, 54 flat tests) and `AuditedMutationIT.java` (1361 lines) together make up 55% of integration-test code. Post-merge fix PRs multiplied test files: `test_chart_render.py` went from 275 to 1871 lines through #116. **Defer**: use `@Nested` grouping, and split by AC.
- **S3:** `scripts/qualify-local-install.sh` is 964 lines with 55 functions and 15 commits; `_helpers.tpl` is 561 lines, of which the `owl-mast.validate` define is 235. **Accept** for now; watch it.

**Pattern divergence**

- **P1:** OM-01.03 put 9 reusable fixture classes in `integrationTest/.../fixtures` instead of `testFixtures`, which the convention says is for reusable fixtures. **Defer.**
- **P2:** there are three config-binding styles; `@Value` defaults repeat `application.yaml`; durations mix `10s` and `PT1S`. **Defer**: pick one convention.
- **P3:** about 5.5k lines of Python and 1.7k of shell have no lint or format gate in CI, and `verify-install-package.sh:63-65` installs unpinned PyYAML/jsonschema. **Fix:** add shellcheck and ruff jobs, and pin the packages.
- **P4:** OM-01.03 exceptions dropped `@Serial`, and `-Xlint:-serial` is undocumented (`build.gradle.kts:117`). 143584b introduced `@AllArgsConstructor` and `@NoArgsConstructor`, which `docs/engineering-conventions.md:41` does not list. **Fix** the doc.
