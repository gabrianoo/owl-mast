## Artifact boundaries and inspection

Both files contain inline CSS, no script, no network dependencies, no external assets, no fixed viewport height and a transparent outer body. System color/font fallbacks keep the document readable without the preview host; exact DESIGN token colors remain unproven by these host-token previews. The accepted owl is inline SVG with unchanged geometry and 1.8 stroke width. All essential text is at least 14px; disclosure/select targets are at least 44px. At widths below 600px, multi-column facts/metrics become one reading column; no wide fixed table is required.

These are static canonical-plus-alternate references, not accessibility or integration tests. Parent performs the requested 728px and 390px preview/render; no preview or render was run by this author. Native expanded disclosures increase height naturally; initial content is arranged to keep the 728px study compact, with supporting calculations and detail initially collapsed.
