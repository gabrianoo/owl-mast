# Issuer samples shared by the chart render tests (deploy/tests/test_chart_render.py) and the backend
# (IdentityPropertiesTest): the chart must refuse every issuer the backend refuses, so that nothing renders
# and then crash-loops the backend, and must accept the hosts java.net.URI parses as a server host.
# One sample per line: "<kind> <issuer>", separated by ONE space. Kinds:
#   accept                    the chart renders it and IdentityProperties accepts it (plaintext not allowed)
#   refuse:<reason>           the chart refuses it and IdentityProperties refuses it FOR THAT REASON
#   chart-refuse              the chart refuses it although IdentityProperties accepts it (a deliberate, narrower chart rule)
#   accept-insecure           an http issuer: both accept it with the plaintext opt-in (allowInsecureIssuer=true),
#                             and both refuse it without, for the reason "insecure"
#   refuse-insecure:<reason>  an http issuer both refuse for that reason even with the plaintext opt-in
# Reasons (the backend's message; the chart has one message for every malformed issuer and one for plaintext):
#   host      no host java.net.URI parses as a server host
#   port      port outside 1-65535
#   userinfo  user info present
#   query     query or fragment present
#   insecure  plaintext http without the opt-in
